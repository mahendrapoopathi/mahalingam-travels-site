# Your Tourist Travels Website

A comprehensive website for a tourist travel service in Tamil Nadu, featuring vehicle booking, tour packages, and customer engagement tools.

## Features Implemented

### ✅ Core Features
- **Responsive Design** - Works on all devices
- **Hero Section** with attractive banner and trust badges
- **Vehicle Fleet Gallery** with detailed specifications
- **Tour Packages** with popular South India destinations
- **WhatsApp Integration** for instant booking
- **Fare Calculator** for price estimation
- **Photo Gallery** with lightbox functionality
- **Customer Testimonials** section
- **Safety & Assurance** highlights
- **Contact Information** with embedded map
- **FAQ Section** with common questions

### 🚐 Vehicle Types
- Mahindra Van (8 Seater) - Family Trips
- Tempo Traveller (12 Seater) - Group Tours  
- Maxi Cab (18 Seater) - Corporate Tours
- Coach Bus (30 Seater) - Large Groups

### 🗺️ Popular Tour Packages
- Chennai → Ooty (2 Days, 1 Night)
- Madurai → Kodaikanal (3 Days)
- Rameswaram → Kanyakumari (1 Day)

### 📱 Mobile Features
- Floating contact buttons (Call, WhatsApp, Book)
- Mobile-responsive design
- Touch-friendly interface

## Setup Instructions

1. **Add Images**: Place your vehicle and destination photos in the `images/` folder:
   ```
   images/
   ├── hero-bg.jpg (main banner background)
   ├── mahindra-van.jpg
   ├── tempo-traveller.jpg
   ├── maxi-cab.jpg
   ├── coach-bus.jpg
   ├── ooty-tour.jpg
   ├── kodaikanal-tour.jpg
   ├── kanyakumari-tour.jpg
   ├── team-photo.jpg
   └── gallery/
       ├── van-exterior.jpg
       ├── van-interior.jpg
       ├── tempo-exterior.jpg
       ├── tempo-interior.jpg
       ├── ooty-hills.jpg
       ├── kodaikanal-lake.jpg
       ├── kanyakumari-sunset.jpg
       ├── rameswaram-temple.jpg
       ├── customer1.jpg
       ├── customer2.jpg
       ├── customer3.jpg
       └── customer4.jpg
   ```

2. **Update Contact Details**: 
   - Replace `+919876543210` with your actual phone number
   - Update email address in contact section
   - Update business address and Google Maps embed

3. **Customize Content**:
   - Update company name from "Your Tourist Travels"
   - Modify tour packages and routes as needed
   - Add your actual customer testimonials
   - Update pricing in fare calculator

4. **Google Maps Integration**:
   - Get Google Maps API key
   - Replace the iframe src with your location
   - Implement interactive map in routes section
